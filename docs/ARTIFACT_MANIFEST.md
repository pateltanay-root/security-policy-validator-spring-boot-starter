# Artifact Manifest

Use this checklist before describing the repository artifact as complete in the paper.

## Validator
- [ ] Validator source code is committed.
- [ ] The paper records the exact commit SHA.
- [ ] A clean checkout builds successfully.
- [ ] A clean test run completes successfully.
- [ ] The exact resolved Spring Security version is recorded.

## Five benchmark applications
- [ ] Application 1: source, README, commit, Java version, Spring Boot version, Spring Security version.
- [ ] Application 2: source, README, commit, Java version, Spring Boot version, Spring Security version.
- [ ] Application 3: source, README, commit, Java version, Spring Boot version, Spring Security version.
- [ ] Application 4: source, README, commit, Java version, Spring Boot version, Spring Security version.
- [ ] Application 5: source, README, commit, Java version, Spring Boot version, Spring Security version.
- [ ] Each app's target Java 17 / Spring Boot 3.3.5 versions are verified from its build file.
- [ ] Third-party license and redistribution permissions have been checked.

## Generator and faults
- [ ] Generator source is committed.
- [ ] Every fault operator is documented.
- [ ] Generator seed/configuration is reproducible.
- [ ] Each injected fault maps to a ground-truth label.

## Policies and ground truth
- [ ] YAML policy files are committed.
- [ ] Ground-truth schema is documented.
- [ ] Clean and misconfigured endpoints are distinguished.
- [ ] Each label identifies endpoint, HTTP method, expected policy, actual condition, and expected violation type.

## Evaluation
- [ ] JSON report parser is implemented and tested.
- [ ] CSV report parser is implemented and tested.
- [ ] DOCX report parser is implemented and tested, if DOCX support is claimed.
- [ ] TP/TN/FP/FN unit of analysis is documented.
- [ ] Precision, recall, F1, and FPR calculations are tested.
- [ ] Validation-time units and measurement procedure are documented.
- [ ] Evaluation outputs can be regenerated from raw reports.

## Raw reports and results
- [ ] Raw reports are preserved without manual edits.
- [ ] Checksums are recorded.
- [ ] Results are generated by the committed evaluation script.
- [ ] Every paper table/figure can be traced to raw reports and scripts.

## Environment
- [ ] OS and version recorded.
- [ ] CPU and RAM recorded.
- [ ] JDK vendor/version recorded.
- [ ] Maven version recorded.
- [ ] Validator Spring Boot/Spring Security versions recorded.
- [ ] Each benchmark app Spring Boot/Spring Security version recorded.
